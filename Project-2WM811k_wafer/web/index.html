WM-811K Wafer Map Pattern Analytics

Project Portfolio by Dashel Ruiz Perez

Topological Data Analysis (TDA) and Machine Learning through a Yield and Process Engineering Lens.

Project Objective: Analyze wafer-level spatial defect patterns (WM-811K dataset), extract interpretable geometry/topology features, and deploy explainable machine learning models to connect spatial signatures to actionable process-engineering hypotheses.

Executive Summary

This project serves as a spatial counterpart to standard high-dimensional tabular sensor data analysis. While traditional sensor models identify which signals fail, wafer map analytics answer where failures occur physically. A wafer map is a spatial record of die-level test behavior; non-random defect clustering strongly suggests systematic manufacturing issues such as thermal unevenness, gas-flow anomalies, or mechanical handling damage.

Instead of treating wafer map classification as a generic convolutional neural network (CNN) image-recognition task, this project treats the maps as manufacturing artifacts. It utilizes Topological Data Analysis (TDA) to extract interpretable shape descriptors, paired with Machine Learning (ML) to automate diagnostic decisions and discover unknown failure modes.

Strategic Alignment: Project 1 vs. Project 2

This study acts as a companion to the SECOM process-signal investigation, rounding out a comprehensive approach to semiconductor yield analytics.

Topological Data Analysis (TDA) Approach

To accurately capture the geometry of wafer failures, this project translates TDA mathematical concepts into practical manufacturing metrics:

  • Point Clouds: Representing failed dies as precise coordinate mappings on the wafer substrate.
  • H0 (Connected Components): Differentiating between random scattered background noise (normal yield loss) and compact, localized defect clusters.
  • H1 (Loops): Mathematically identifying ring or donut-like spatial structures that indicate rotational or flow-based chamber issues.
  • Persistence: Measuring how stable a shape feature is across distance scales to separate real tool signatures from random test noise.

Machine Learning Integration

TDA serves as advanced feature engineering, while the ML layer acts as the decision engine. Because process-engineering transparency is paramount, the ML strategy prioritizes models that offer clear feature importance and anomaly detection over black-box predictions.

ML Strategy Algorithms Used The Yield Engineering Value
Interpretable Classification Random Forest, XGBoost Feature Importance: Models ingest TDA summaries to explicitly reveal which topological shapes (e.g., H1 loops) define a specific tool failure.
Unsupervised Discovery UMAP, DBSCAN Unknown Pattern Detection: Automatically groups similar wafers to discover emerging failure modes before a human yield engineer manually labels them.
Anomaly Detection Isolation Forest Automated Alerts: Trained purely on "normal" baseline wafers to flag topological deviations, acting as an early warning system for catastrophic tool drift.
The Black-Box Baseline CNN (ResNet architecture) The Benchmark: Establishes a raw image-processing baseline to prove that the TDA + Interpretable ML pipeline achieves high accuracy without sacrificing explainability.

Deliverables & Outcomes

This project culminates in a defect-pattern atlas, a spatial feature table, and a Process Interpretation Matrix. By combining spatial density metrics with topological persistence and interpretable ML, the resulting pipeline provides yield engineers with explainable, geometry-based insights to accelerate root-cause investigations.

Note: This project relies exclusively on the public WM-811K dataset. No proprietary, confidential, or production manufacturing data is included in this analysis.
